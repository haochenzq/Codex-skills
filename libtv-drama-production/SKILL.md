## 路线选择

LibTV与Seedance直连是独立路线，由用户明确指定，不设优先级、不同时启动、不互相调用。沿用本次已指定路线；尚未指定且影响执行时只澄清路线，不擅自比较或切换。LibTV内部使用Seedance模型仍属LibTV路线；已有任务沿原平台身份查询恢复。

## 执行入口

优先LibTV插件；网页专有功能、页面核对或下载补足使用已连接的Edge，操作后读回结果，不要求每次打开浏览器。现成合格素材直接复用；需生图时使用imagegen和ChatGPT生图，或本片明确采用的LibTV图片工作流；复用合格素材，不因第三方模板重复生成。封面按本项目封面规则调用video-cover的其他封面分支；声音、后期和预演按项目方案选择，本地工具可在前期或后期参与。

- 制作或修改短片：按下文组织已确认方案，不重新编写编导维护的创作原件。
- 插件连接、上传、生成、恢复、时间线或下载：读[操作参考](references/operations.md)对应章节。
- 仅素材入库或角色音色参考：读[资产与音色执行](references/assets-and-voice.md)对应章节，不启动整片流程。
- 仅查询或恢复：沿原任务身份及有效授权处理，不新建收费生成。

导出使用 `watermark=remove`，本地不主动加水印；权益不足或接口失败时按项目要求报告阻塞。只修受影响部分，不重复生成可用镜头，不为封装或熟悉功能重跑测试。

## 原片交付

LibTV直接生成的视频原片下载后直接交付，只确认下载成功、文件存在且非空；不探测原片规格或音轨，不抽帧、试听、完整解码或审查内容质量，不自动后期、转码或补生成。由用户查看并提出修改；生成前输入核对、任务状态查询和防重复提交仍按操作流程执行，不属于审片。

## 制作顺序

需要后期的整片制作可按以下依赖组织；已有方案和素材直接复用，单项操作只执行所需阶段。仅生成原片时按上节直接交付，不自动进入修复或后期。

需求与预算 → 剧本和声音方案 → 角色/场景/道具 → 分镜与参考 → 按需预演 → 视频与声音 → 局部修复 → 后期 → 无水印下载与验收。

| 阶段 | 必要工作 |
| --- | --- |
| 需求 | 对齐风格、用途、时长、画幅、模型、清晰度、声音和预算，定位作品项目。 |
| 剧本与资产 | 明确人物目标、因果、对白和结尾；固定角色身份、服装、场景布局与关键道具。 |
| 分镜 | 用稳定镜号说明构图、动作、视线、运镜、对白停顿、音效和接缝，绑定真实参考。 |
| 生成 | 按当前模型契约预检并执行，回读任务和产物；画布按作品需要组织，不机械建全套分组。 |
| 修复 | 声音问题改声音层，节奏改时间线，身份外观改参考，空间调度回预演；只重做受影响下游。 |
| 后期 | 每个版本一份主时间线；裁取、混音、字幕、转场和编码按效果选平台或本地，保持剧情因果。 |
| 交付 | 下载用户要求的成果，按“执行与收尾”的对应检查范围核验并交付，复用已有有效结果。 |

## 按需路线

- **原生音画同步**：适合短对白与临场表演。明确台词、发声人物、停顿、环境和动作声；声线、口型及连续性的检查按“执行与收尾”的对应范围执行；贯穿音乐独立组织，避免每镜音乐断裂。
- **先配音再驱动画面**：适合固定声线、多镜对白或精确时长。先试听并确定音色与情绪，再按实际音频定镜长、绑定模型支持的参考；音频参考不保证逐帧口型。区分设计、克隆、登记与合成的接口及效果；当前需求和有效授权已明确的步骤直接执行，不逐接口重复确认。
- **预演**：简单镜头直接生成；多人站位或跟拍先评估内置导演台；复杂空间、精确动作、道具接触和长运镜按需用本地Blender MCP。直传插件与完整2.5制作技能的选择见项目预演规则，不强制安装或使用。白模管动作与机位，场景图管环境，角色图管身份；不自动安装额外扩展。
- **本地协同**：FFmpeg/video-use用于明确剪切、混音和编码，Remotion用于精确图形与字幕，Manim仅用于数学/技术动画。需要时用已有ASR，不因后期自动重新配音或给无对白素材转写。前期同样可用本地，不必等平台失败。
