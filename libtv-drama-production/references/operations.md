# LibTV 操作参考

适用范围与项目规则读取见[技能入口](../SKILL.md)。素材入库及角色音色参考见[专用执行步骤](assets-and-voice.md)，网页独有细节见[项目功能导航](D:/Codex项目文件夹/LibTV制作/AGENTS.md)。本文按需读取；接口、模型、会员权益及价格以执行时的工具契约和页面为准，不沿用旧快照。

## 连接、素材与生成

1. `doctor`确认身份与连接，核对账户/空间，用`target_project`定位精确画布UUID；不知道目标时先查项目列表。项目数字ID、空间ID和画布UUID不互换，教学画布不当作品项目。
2. 读取所需节点或快照，保留真实ID与revision；同名对象按ID消歧，不按列表位置认定身份。网页操作后读回状态，避免人工、Agent和插件同时修改同一对象。
3. 外部素材走`upload_ticket` → 按签名要求上传字节 → `upload_complete` → `upload_media`审核挂图。请求头与签名匹配，不擅加Content-Type或改签名URL。
4. 先搜模型、读`get_model`实时schema，再建参考关系并`validate_generation_plan`。创建引用用`left/right`，更新用`leftEnsure/Add/Remove`等；媒体list和顺序由连线重算，不直接写params，不改节点type/action身份。
5. `generate_video(run=false)`仍会创建节点，按返回的`continueTool`继续同一节点。明确未提交且报`SNAPSHOT_REVISION_MISMATCH`时先读最新revision；已受理任务只恢复原task_id。实际生成调用尚在等待时不另发生成或查询；调用结束且要求恢复时才回读原任务。
6. 收费操作使用稳定幂等键，保存当前任务所需的project/node/resource/task/run/operation身份。完成后检查实际输出数量、媒体和绑定；受理、存字段或出现连线不等于可用产物。

## 功能与入口

| 需要 | 插件或网页路线 | 关键区别 |
| --- | --- | --- |
| 画布组织 | 项目、节点、连线与分组工具；网页右键复制、资产、分组 | 复制后检查连线；分镜组、普通组、分镜表不同，整组执行可能重生全部。 |
| 新版剧本 | `create/list/read_screenplay`及VFS；修改先`requireVersion=true`取ETag，再`write_screenplay` | 正文不是旧Script V2表；未知写入查原operationId。 |
| 分镜表 | `create/read/edit_script_v2`；网页拆镜头→关联资产→合成提示词→选镜生成 | 保留shotId/revision；表内资产描述不是已生成媒体。 |
| 导演Agent | `run_agent`的omni、原创、改编、directing模式 | 非普通生成的前置要求。使用时明确预算、autoGenerate和真实节点；模式/模型/节点绑定会话。模板先查真实selection，不能把名称当正文已读取。 |
| 图片与角色 | 角色造型室、角色库；生成器预设或`/`；图片顶栏多角度、全景、灯光、表情 | 检查身份、服装、道具和空间一致性；角色卡不等于模型主体库或通用资产库。 |
| 图片编辑 | 高清菜单下扩图、重绘、擦除、抠图、裁剪；焦点编辑/镜头聚焦 | 高清不等于恢复真实细节，相机外观控制不等于物理模拟。 |
| 宫格与参考 | 宫格切分→校对边界顺序→发生成器/分镜组；AutoLink逐项确认 | 整张宫格不直接当连续视频，提示词“图片1”不代替真实引用。 |
| 视频与修复 | 所选模型支持的图像/混合/音频参考、编辑、续写；网页片段重拍 | 整段编辑与选段重拍不同，不能编造editSegments；局部处理也可能收费。 |
| 样片升级 | `get_draft_video`后`promote_draft_video(run=false)`预检与报价 | 核对有效期、输出编号及权限；按已对齐方案升级，沿用原任务参数。 |
| 长视频 | 网页独立长片创作入口 | 平台长片不等于普通模型单次长时长，不能超schema写duration。 |
| 媒体理解 | `inspect_media`、`check_continuity`及当前可执行分析路线 | 目录或能力地图不证明服务能运行；抽帧不证明表演、触碰或口型质量。 |
| 导演提案 | 随包Treatment技能 | 用于作品提案，不是每次制作的必需步骤，也不自动公开分享。 |

Agent运行保存runId/agentSession；补充要求、回答和停止绑定同一运行，确认终态后再接手。未知结果查询原运行，Agent自述完成还须查实际画布产物。

## 声音与预演

- 生成前按模型支持明确音频开关，不统一假定默认静音；直接生成原片按[原片交付](../SKILL.md#原片交付)，不额外检查音轨、台词、声线或口型。后期处理涉及声音时，只核对受影响音轨与明确异常。
- 独立配音、音色设计/克隆、音乐和音效用当前支持的模型。先试听角色适配、情绪、清晰度和自然度；只用获授权声音素材。单位、参考限制和字段按schema核对，不臆造emotion等参数。
- `register_voice`只登记既有声音，`set_character_voice`只建立关联，均不代替克隆或配音生成。
- 音频顶栏提供截取、变速和切分；保留发音、呼吸及尾音，变速后检查口型。视频“分离音视频”只拆画面与音轨；“人声分离”是AI处理，需听审残留和损伤，不保证无损三轨。
- 内置导演台：添加角色/几何体→布置位置→机位和注视目标→角色运动/摄像机运镜→截图或预演回画布。角色与相机路径分开设置，跟拍核对距离、高度、角度和遮挡。
- Blender按工作流选用；白模、场景和角色参考分工明确，动作、对白、道具与相机使用同一时间基准，不能只做相机游览。

## 剪辑与交付

第1—4步仅用于任务已要求的剪辑、混音或合成；直接生成原片跳过这些后期步骤，下载后按[原片交付](../SKILL.md#原片交付)处理。

1. 平台基础合成：连接视频/音频→时间轴排序、裁取、音轨调整→预览→合成。智能剪辑先核对计划，再看实际时间轴、字幕、音乐和叙事变化。
2. 插件先`read_timeline`，按需`apply_timeline_edit(mode=plan)`，以原revision应用并读回。高级变速、转场、变换、字幕是否进入最终渲染要单独确认。
3. `export_video`按clips顺序和源入出点导出；整体audio_volume/video_volume为0–1。支持的转场及音轨控制以当前schema为准，不假定所有时间线效果都会烘焙；必要时用网页或本地实现。
4. 导出前检查`export_readiness`，提交后跟进原task_id及实际输出节点，合成可能另建成片节点。核对输出音轨和播放；字段保存、有限负增益或空转写不证明静音。
5. `prepare_project_delivery`显式选择所需items，遵循工作流的水印规则。以`read_node`确认输出，只有节点持久化且对应输出的ID才传resourceId；单输出仅有URL时可省略resourceId并指定outputIndex，不照抄任务artifact的资源ID。
6. `awaiting_host_save`只是交付清单，须逐项下载或保存inlineText并检查实际文件。网页下载先监听download事件取得保存路径；URL或点击成功不算交付。
7. 后期成片复用已有结果，只做本次改动与明确异常的必要检查；原片只确认下载成功、文件存在且非空，不抽帧、试听或解码，不重复验收。

基础顺序合成、导出和下载在本次实测中未见额外LibTV扣分，本地处理不消耗LibTV积分；不能推断AI修复、配音/音乐、声音分离或高清升级免费，实际使用时核对报价。

## 本地衔接与故障恢复

运行方式见[共享环境](C:/Users/lenovo/.codex/runtimes/personal-video/RUNTIME.md)，本地剪辑模块按需查[video-use](C:/Users/lenovo/.codex/skills/video-use/SKILL.md)。不把旧整片技能的模型排除项、声音默认迁入新路线。本地timeline runner的能力按当前实现确认，不能臆造复杂转场或多轨字段；Edge登录状态与Remotion渲染浏览器不共享。

| 现象 | 处理 |
| --- | --- |
| ready但项目不可读 | 核对OAuth与网页身份、空间、UUID及当前项目列表；连接就绪不代表业务可用。 |
| 节点不能参考 | 查审核、永久原件、Resource、连线顺序和模型输入限制，修受影响引用后预检。 |
| 生成或写入超时 | 查询原task/run/operation；unknown不换键自动重发，也不覆盖已变更节点。 |
| 网页看不到节点 | 先“适合屏幕”；画布可能只渲染视口内节点，不因此重建媒体。 |
| 网页与插件不一致 | 读最新revision，排查人工或Agent并发编辑；不能静默覆盖。 |
| 音轨或高级效果没生效 | 查真实输出、时间偏移、增益和渲染支持，再局部修复。 |
| 导演台打不开 | 查浏览器、WebGL和图形加速；设置变更按授权处理。 |
| 模型存在但不能执行 | 查会员、余额、权限、输入与报价；目录不是运行授权。 |
| 下载404或来源变化 | 分别查权益、节点真实资源绑定和原回执；不自动改取原件绕过水印。用户明确要求重试时沿用原键与参数，成功后按技能对应交付路径确认下载结果。 |

`get_web_operation_status`可能只读保存回执，不代表实时上游进度。下载404需分别核对权益、节点资源绑定和原回执，不能直接认定会员不足。远程服务端不在本地插件包中，不以重装或改创作脚本代替后端修复。

需要教学时按“目标→当前入口→填写内容→预期结果→成功检查”说明；能代办的直接完成，只把必须用户本人处理的步骤交回。
