# 工具、参考与实测范围

本路径的最终视频由Seedance生成。工具按需要选择，执行与交付边界以 `SKILL.md` 为准。

| 能力 | 本路径用途 |
| --- | --- |
| Codex图片能力 | 按需制作或编辑角色、场景、美术与分镜参考；读取imagegen |
| 本地三维、Remotion、FFmpeg | 按需准备粗模、动态预演、合规参考片段或抽帧；不是最终合成的必经步骤 |
| Seedance | 用用户本次确认的型号与模式完成最终视频，返回原片 |
| 豆包语音2.0 | 需要独立台词/配音或声音参考时使用；转写读取volc-video-analysis |
| MediaKit/视频分析 | 仅在上传桥接、参考分析等实际需求下调用；不审查返回原片 |

计划分镜用于表达意图，生成参数按所选型号当前官方文档核实。模型响应的镜头时间与本地帧精度分开，不把同一请求、同一种子或白模参考当作严格复现保证。

历史证据：2026-10-03的Mini文生视频提交、查询、下载见[最小验收](D:/Codex项目文件夹/构建相关/02-技能与插件/SK001-火山API接入/production-smoke/README.md)。2026-10-04自媒体作品已有Seedance2.5、五图参考、15秒720p竖屏请求与原片下载记录，见[执行记录](D:/Codex项目文件夹/自媒体相关/视频制作/01-六位AI角色展示-15S/API生成/20261004-15S-720P-02/执行结果.json)。这些证明特定任务完成，不代表其他型号/输入组合或当前额度都已验证；声音和口型效果未试听验证。

当前适配器未实现Draft、视频编辑或延长；需要这些能力时核实接口与适配器，不把平台存在某功能当成本机已接通。本次技能拆分不新增云验收。
