# 原片切点与中文字幕

选段和字幕都使用原素材秒数，输出偏移由入口计算；多素材不能把各自时间混成同一原片时间。

## 保留方案

```json
{
  "fps": 30,
  "ranges": [
    {"source": "video_001", "start": 0.06666666666666667, "end": 2.2},
    {"source": "video_001", "start": 2.8666666666666667, "end": 4.4}
  ],
  "caption_groups": {"video_001": [[0, 9], [9, 14]]}
}
```

这是8秒历史测试素材的局部示例，不是默认剪辑策略。`source`取自 `status`；每个range是保留的半开区间，顺序即输出顺序。所有切点须在所选输出帧率的帧边界上，不能越过原片时长。入口拒绝切穿已识别的词；仍要从原片核对ASR误差与词前后余量。

- 脚本不决定删谁或删多少。Codex根据语义、重录完整性、视觉衔接及用户意图写明确保留区间，另按删减类型保存简短理由，如“口误重录”“无效等待”。含义变化或涉及否定、数字、前提、论证关系及重排的改动对应具体原话单独说明；已确认策略下的常规删减不逐条要求用户审批。理由在本次剪辑方案或交付说明中简述，不要求长期另存记录，也不添加入口不接受的方案字段。
- 切点留出合适的起音、尾音和呼吸，避免30ms切边淡化影响词头/词尾。时长目标与完整意思冲突时先展示取舍，不丢否定、数值或前提来压时长。
- 单素材保持原表达顺序为通常选择；重排或拼接改变意思时对齐具体内容。多条重录按事实完整、清晰表演和衔接选择，不一概“最后一条最好”。

先按合理起音、尾音及呼吸余量选切点；仅对本次改动或明确异常局部试听和微调，不集中逐切点听审。难以取舍时才按需提供短片对比，不新增分项验收记录。

## 字幕

`caption_groups`的每项 `[a,b]` 表示该素材顶层words的索引a到b之前。须把全部保留的词按顺序恰好覆盖一次；脚本会按剪辑区间拆分分组并计算输出时间。语义短句优先，长句在自然分句处换字幕，不能拆断数字单位、人名、术语或否定关系。标点来自原句与词文本的对齐；对齐失败会记录问题，须人工核对，不能猜时间。

未提供分组时按标点、停顿和16字符上限生成草案，可用 `max_caption_chars`（4至50）调整。草案不保证语义正确；本次改动或明确异常按需修订，不另设全字幕复审。中文词之间不加空格；ASCII单词按需保留词间空格。字幕认错时修订本次字幕，不能让字幕与实际说话含义不一致。

字幕样式与横竖屏定位先读取当前项目的参数规则，并沿用本次已确认设置；正常适配不重复询问，只有超出授权或确需改变设置时再对齐。本技能引用项目参数，不另存副本，工具内置默认值不覆盖项目要求。烧录用ASS声明正式画布尺寸，避免SRT虚拟画布使字号失真；仅按用户要求或项目交付规则提供SRT等配套。`subtitle_style`接受ASS的逗号分隔 `key=value`（字体、字号、描边、位置等），字号单位对应ASS声明画布；预览同比缩放。检查横竖屏安全区、遮挡及实际文字宽度，不默认套英语两词大写模板。

认错字可用 `word_corrections: {"video_001": {"3": "正确文本"}}` 修改第4个词（words[3]）的显示文字，不改原始ASR、词时间或声音。首版支持词显示文本和分组修订，沿用词时间映射。修改必须符合原片实际表达；不是生成新台词。手工改过生成的SRT/EDL时先保留用户文件，建立新的剪辑目录并导入同job，把改动转成新方案的分组/修订再渲染，仍不重识别；仅修改SRT不会改变烧录用的ASS。用户另调字幕时间、删词或换行等不能由该接口表达的修改，按实际字幕文件扩展工具链处理，不丢弃用户改动。

`grade`沿用video-use；`overlays`每项只接受 `file`、`start_in_output`、`duration`，文件路径可为绝对路径或相对于剪辑目录，时间属于输出片。第一版字幕在叠加之后；补镜头、背景音乐、镜头裁切和降噪等额外处理在用户需要时走工具链，保持原声与时间映射，不加入口不读取的字段。
