# 工具链选择与能力边界

仅选择本路径需要的能力；最终成片由自身工具链完成。遵循 `SKILL.md` 的路径、确认和交付要求。

| 能力 | 用途与边界 |
| --- | --- |
| Remotion | 图形、文字、UI、动画和精确合成；依赖版本与浏览器见公共运行说明，透明导出有历史验收，读取相应Remotion技能 |
| video-use/FFmpeg | 用户素材剪辑、字幕、调色、音频与编码；按实际素材需求使用专业技能和全局helpers |
| FFprobe | 素材规格、区间安排与最终输出技术检查；以真实媒体为准 |
| 程序绘图/三维 | 几何、数据图形或镜头运动；已有抽象程序三维演示，不声称完整写实人物CG已接通 |
| Codex图片能力 | 按需创作或编辑角色、场景、美术和其他图片素材；读取imagegen |
| 豆包语音2.0 | 按需独立配音；转写/时间定位读取volc-video-analysis，无语音不强制调用 |
| 首版时间轴运行器 | 硬切、透明标题、音乐、一路配音及SRT；不是所有效果的唯一合成器 |

Manim、LaTeX与dvisvgm已共享部署，精确图形、公式和技术解释动画按需直接调用；读取manim-video技能及公共运行说明。Blender及其他新三维工具仍先查可用性，不默认已部署。

图片、独立语音或素材分析服务按用户实际需求使用；新增能力先核实需求、可用性及授权，Seedance始终排除在本路径之外。素材、动画、源工程与最终编码分层保存，实际音画位置依据编辑时间轴确定。
