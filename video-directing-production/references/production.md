# 生成与建卡

## 定稿输入与建卡前核对

向负责本镜的 [sd25-pe](<C:/Users/lenovo/.codex/skills/sd25-pe/SKILL.md>) 子 Agent 交接已确认的画面和人物表演、原文台词、实际接点、生成方式、素材职责和既定摄影条件。需要补素材时参照[参考素材](references.md)，由负责本镜的子 Agent 说明缺项及用途。定稿需要修订时，反馈具体要求或事实。

建卡前一次核对正文与已确认画面、表演及接续，逐句核对台词、说话人、对象和顺序。每句台词只写一次。核素材引用和实际挂载，参数单独填入卡片。单镜时长影响剪辑接点或整集约束时，复核受影响的时长。

仅调整参数或素材绑定时，不无故重写提示词；已有绑定不擅自替换。

## 建卡与回读

优先用 LibTV 插件，以 `run=false` 创建草卡，缺槽位再用网页。按清单挂载确认素材，素材引用标签只按实际绑定转换。用户在平台提交。未提交草卡可更新，已提交任务重跑新建卡。

保存后一次回读提示词、参数和绑定，对照定稿及清单。仅改参数或绑定时回读变更字段及受影响引用。平台预检查通过状态，实片表演与连续性须看片核对。
